Kubernetes • Calico • Terraform • IAM • Security Testing

??? Security Overview

This prototype demonstrates Zero Trust network segmentation between two isolated applications running on Kubernetes.

Every application namespace uses default-deny policies, with only explicitly authorized communication permitted.

?? Zero Trust Controls

  • Default-deny ingress and egress
  • Explicit frontend-to-backend authorization
  • Cross-application traffic isolation
  • DNS-only egress where required
  • Terraform-managed IAM least-privilege policies
  • Automated attack-test scripts
